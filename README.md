# 📱 Toast and Notification Android App

## 📌 About the Project
This project is a simple Android application developed using Java and XML in Android Studio. It demonstrates how to implement user input, navigate between screens, and display Toast messages and system notifications.

The main purpose of this project is to understand and demonstrate core Android development concepts, including Intents, event handling, data passing, and system-level feedback.

## ✨ Features
- **👤 User Profile Creation:** Captures user input (Name, Mobile, Username) using `EditText` fields.
- **🔄 Multi-Screen Navigation:** Uses `Intents` to pass user data from the main screen to a dedicated profile screen.
- **🔔 Toast Messages:** Displays short, temporary feedback confirming profile creation.
- **📢 System Notifications:** Uses `NotificationCompat` and `NotificationManager` to push custom notifications to the Android notification panel (including Android 8+ Channel ID and Android 13+ permission handling).
- **🖱️ Event Handling:** Demonstrates handling button clicks across multiple activities.

## 🛠️ Technologies Used
- **Programming Language:** Java
- **UI Design:** XML
- **IDE:** Android Studio
- **Platform:** Android
- **Build System:** Gradle

## 🎯 Project Objective
The objective of this project is to learn and practice passing data between Activities and implementing system feedback (Toasts and Notifications) using Java. It helps beginners understand how Android applications respond to user interactions and manage background system services.
