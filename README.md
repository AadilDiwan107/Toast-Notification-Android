# 📱 Toast and Notification Android App

## 📌 About the Project

This project is a simple Android application developed using **Java and XML in Android Studio**. It demonstrates how to implement Toast messages and system notifications in an Android application.

The main purpose of this project is to understand and demonstrate the basic concepts of Android development, including event handling, button click events, Toast messages, and notifications.

## ✨ Features

- 🔔 **Toast Messages:** Displays short messages to provide feedback to users.
- 📢 **Notifications:** Shows notifications in the Android notification panel.
- 🖱️ **Button Click Events:** Demonstrates how to handle button clicks.
- 📱 **Simple User Interface:** Provides a straightforward and user-friendly interface.
- ☕ **Java Programming:** Implements application logic using Java.
- 🎨 **XML Layouts:** Designs the application interface using XML.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **UI Design:** XML
- **IDE:** Android Studio
- **Platform:** Android
- **Build System:** Gradle

## 🎯 Project Objective

The objective of this project is to learn and practice the implementation of Toast messages and Android system notifications using Java.

It helps beginners understand how Android applications respond to user interactions and display feedback through Toast messages and notifications.
